# Electronic Checklist

Recreates aircraft electronic checklists (ECL). Checklists are grouped by aircraft,
and each checklist holds an ordered list of items you check off as you work through
it. Two versions live in this repo:

- **Desktop app** (`app.py` / `checklist_data.py`, root of the repo) — a Python/Tkinter
  app for Windows/macOS/Linux, storing data in a local `data.json`.
- **Web app** (`docs/`) — a mobile-friendly installable PWA with the same feature set,
  storing data in the browser. Live at
  **https://tsing-code.github.io/AircraftChecklists/** — see
  [Using it on Android](#using-it-on-android) below.

## Features

- **Aircraft-grouped checklists** — add as many aircraft as you like, each with its
  own set of checklists (Before Start, Taxi, Before Takeoff, etc.)
- **Menu-driven navigation** — pick an aircraft, tap a checklist to open it, and it
  automatically returns to the checklist menu once every item is checked
- **Text + result items** — items can have a challenge and a response
  (`Packs.......................................Auto`), styled with a dot leader
  like a real ECL
- **Separators** — insert a solid divider between items to mark a pause point
  (Airbus-style)
- **Completion tracking** — completed checklists show a checkmark in the aircraft
  menu until reopened
- **Export / import** — export a checklist (or every checklist for an aircraft) to
  a `.json` file, and import checklists from a file into any aircraft

## Requirements

- Python 3.10+ (uses only the standard library — `tkinter`, no extra packages)

## Running it

```bash
python app.py
```

On Windows, double-click `Run Checklist.bat` to launch without a terminal window.

## Building a standalone .exe

Requires [PyInstaller](https://pyinstaller.org/):

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "Electronic Checklist" app.py
```

The exe is written to `dist/Electronic Checklist.exe`. It's fully standalone — no
Python install needed on the target machine — and stores `data.json` next to
wherever the exe itself lives, so it can be copied anywhere. Build output
(`build/`, `dist/`, the generated `.spec` file) isn't tracked in git; rebuild from
source whenever you need a fresh exe.

## Data storage

Checklist data is stored in `data.json` next to the app (not tracked in git — a
sample Cessna 172 checklist is created automatically on first run). Back it up or
share it using the in-app **Export** / **Import** buttons under **Edit Checklists**.

## Using it on Android

Open **https://tsing-code.github.io/AircraftChecklists/** in Chrome on your phone,
tap the &#8942; menu, and choose **Install app** (or **Add to Home screen**). It
installs as a full-screen app icon with offline support — no Play Store, no APK.
Checklist data is stored locally in the browser (not synced with the desktop app's
`data.json`); use the in-app **Export**/**Import** to move checklists between them.

The web app (`docs/`) is plain HTML/CSS/JS with no build step and no dependencies -
edit and refresh to iterate. To preview it locally:

```bash
python -m http.server 8000 --directory docs
```

then open `http://localhost:8000`. It's served on GitHub Pages straight from the
`docs/` folder on this branch - pushing to `master` updates the live site. App icons
are generated by `gen_icons.py` (`pip install pillow` then `python gen_icons.py`) if
you ever want to change them.
